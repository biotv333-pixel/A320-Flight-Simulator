# Prototype scope
This is a scripted, block-model multiplayer A320 and approximate JFK-themed world, **not** a geometrically accurate JFK map or study-level flight simulator.
- Server owns aircraft motion and accepts controls only from the current PilotSeat occupant.
- Client shows basic controls and sends keyboard commands.
- Four named runways and five terminals are illustrative placeholders.
- No cockpit systems, flight management, realistic aerodynamics, navigation, persistence or ATC.
- This implementation needs Roblox Studio runtime testing. Publish only to the isolated test experience first.
